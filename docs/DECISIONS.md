Every product and technical decision, with its date, the reasoning, and the handoff that landed it. Moved out of `CLAUDE.md` by handoff 19 because it had grown to 43% of a file loaded into every Builder session. **No entry was reworded, reordered or dropped on the way.**

Read the entries for the area you are about to change before changing it. **Add to this file in the same commit as the work.**

> **Ruled ≠ landed.** A line here records what was *decided*, not what exists in the code. Tag each one **`[ruled]`** when the Architect makes it, and change it to **`[landed <commit>]`** only when a Builder report confirms it shipped. The Architect may write `[ruled]`; only a report moves a line to `[landed]`. `docs/STATUS.md` lists **landed** work only.
