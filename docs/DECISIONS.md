Read the entries for the area you are about to change before changing it. **Add to this file in the same commit as the work.**

> **Ruled ≠ landed.** A line here records what was *decided*, not what exists in the code. Tag each one **`[ruled]`** when the Architect makes it, and change it to **`[landed <commit>]`** only when a Builder report confirms it shipped.
